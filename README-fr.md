## Étiquettes

Chaque entrée indique ce qu'elle est. Les étiquettes à côté aident à choisir : officiel quand cela vient de celui qui définit la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'usage, API et SDK selon la façon de l'intégrer.
