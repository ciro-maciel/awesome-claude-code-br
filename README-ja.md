Claude Codeをポルトガル語で使いたい人や、ブラジルのことを知っているskillを探している人向け。CLT、ABNT、CNJ、Simples。Anthropicが公開しているものから始まり、ブラジルのコミュニティが作ったものへと続きます。各リポジトリは公開されており、2026年に活動がありました。
