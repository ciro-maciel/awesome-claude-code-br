## Tags

Each item says what it is. The tags next to it help you choose: official when it comes from whoever sets the standard, open source when the code is published, free or paid based on the usage model, API and SDK based on how you integrate. Items tagged "by the author" are made by Ciro Cesar Maciel and follow the same rules as all the others.
