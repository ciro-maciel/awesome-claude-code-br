## Метки

Каждый пункт говорит, что это такое. Метки рядом помогают выбрать: официальный, когда это от того, кто задаёт стандарт; открытый код, когда код опубликован; бесплатно или платно по модели использования; API и SDK по способу интеграции. Пункты с меткой «от автора» сделаны Сиро Сезаром Масиэлом и подчиняются тем же правилам, что и все остальные.
